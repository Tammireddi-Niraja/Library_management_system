# Library Management System - UML Class Diagram

## Project Overview
This project presents the UML Class Diagram of a Library Management System. The system manages books, members, librarians, loans, reservations, categories, and fines.

## Objectives
- Understand UML Class Diagrams
- Design an object-oriented library management system
- Learn relationships between classes
- Practice software design concepts

## Classes Included
- Member
- Librarian
- Book
- Loan
- Category
- Reservation
- Fine

## Features
- Member registration
- Book management
- Book borrowing and returning
- Book reservation
- Category management
- Fine calculation
- Loan history

## Relationships
- Member borrows books through Loan.
- Librarian issues and returns books.
- Books belong to Categories.
- Books can be Reserved.
- Late returns generate Fines.
